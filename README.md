# WeaveLens

WeaveLens is an infrastructure observability tool that discovers AWS resources, maps their relationships, and visualizes them on the web.

## Current Status

Project initialization phase. The repository structure, Go module, and development tooling are in place. Core functionality is not yet implemented.

## Roadmap

1. Project foundation and Go skeleton
2. Domain modeling and architecture
3. AWS resource discovery
4. Infrastructure graph construction
5. gRPC API
6. NATS event streaming
7. Web visualization
8. Resilience patterns
9. Graph export
10. Observability and security
11. Microservices evolution

## Prerequisites

- Go 1.26+
- Make
- Git

## Development

```bash
make build
make test
make lint
make run
```
